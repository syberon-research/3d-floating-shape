# Assignment 3 - 3D Floating Shape

A C++ 3D software renderer created for Computer Science Assignment 3.

## Files

- `main.cpp` - Main program and 3D rendering code
- `Makefile` - Compiles the program

## How to Run

Compile with:
make

Run with:
./hw3

## Controls

S → changes the 3D shape
X → shows/hides the coordinate axes
Left Arrow → rotates the view left
Right Arrow → rotates the view right
Esc → closes the program
